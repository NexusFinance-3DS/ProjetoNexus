# ProjetoNexus
Nexus Finance é um sistema web de gerenciamento financeiro pessoal desenvolvido como Trabalho de Conclusão de Curso (TCC). O App permitira cadastrar e controlar receitas e despesas, acompanhar o orçamento por meio de gráficos e relatórios e auxilia os usuários na organização de suas finanças, incentivando o planejamento e a educação financeira.
