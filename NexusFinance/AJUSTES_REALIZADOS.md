# Integração final

O aplicativo agora usa a API Python da pasta ../backend. As telas de autenticação, fluxo financeiro, dashboard, metas, relatórios, notificações, contas, categorias e configurações leem e gravam dados reais.

Os estilos ficam em src/styles.js. Os componentes compartilhados ficam em src/components, fora das rotas do Expo. Os formulários mantêm tratamento de teclado.

Leia o README.md na raiz do projeto para iniciar o banco, a API e o Expo. O aplicativo requer a API em execução. Configure EXPO_PUBLIC_API_URL em .env para acessar a API pelo celular.
